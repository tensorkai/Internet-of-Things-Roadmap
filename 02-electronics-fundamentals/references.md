# Electronics references

[Module home](README.md) · [Photo credits](assets/README.md)

The lessons contain original worked examples and exercises. These primary educational and manufacturer references provide further explanation. For an actual build, record the exact component datasheet revision and instrument manual in the workbook; a general tutorial cannot establish a particular part's limits.

| Topic | Reference | Use it for |
| --- | --- | --- |
| Basic quantities | [SparkFun: Voltage, Current, Resistance, and Ohm's Law](https://learn.sparkfun.com/tutorials/voltage-current-resistance-and-ohms-law) | Electrical relationships and units |
| Dividers | [SparkFun: Voltage Dividers](https://learn.sparkfun.com/tutorials/voltage-dividers) | Divider behavior and output loading |
| Physical prototyping | [SparkFun: How to Use a Breadboard](https://learn.sparkfun.com/tutorials/how-to-use-a-breadboard) | Contact strips, power rails, circuit construction |
| Measurement | [SparkFun: How to Use a Multimeter](https://learn.sparkfun.com/tutorials/how-to-use-a-multimeter) | Modes, probes, and measurement technique |
| Capacitors | [SparkFun: Capacitors](https://learn.sparkfun.com/tutorials/capacitors) | Packages, charge storage, decoupling |
| Input bias | [SparkFun: Pull-up Resistors](https://learn.sparkfun.com/tutorials/pull-up-resistors) | Defined input states |
| Logic specifications | [Texas Instruments: Understanding and Interpreting Standard-Logic Data Sheets](https://www.ti.com/lit/an/szza036b/szza036b.pdf) | Input/output limits and datasheet terminology |
| ADC fundamentals | [Microchip: A/D Converter Basics](https://developerhelp.microchip.com/xwiki/bin/view/products/data-converters/adc-specs/basics/) | Conversion range and codes |
| ADC code width | [Microchip: ADC Code Width](https://developerhelp.microchip.com/xwiki/bin/view/products/data-converters/adc-specs/code-width/) | Reference voltage divided by number of codes |
| PWM | [SparkFun: Pulse Width Modulation](https://learn.sparkfun.com/tutorials/pulse-width-modulation) | Duty cycle and switched outputs |
| Motor switching | [Adafruit: Arduino Lesson 13, Transistors](https://learn.adafruit.com/adafruit-arduino-lesson-13-dc-motors/transistors) | Transistor drive and inductive protection |
| Driver example | [Adafruit: MOSFET Driver](https://learn.adafruit.com/adafruit-mosfet-driver?view=all) | A documented driver and its component ratings |
