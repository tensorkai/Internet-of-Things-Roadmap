# Smart Home and Interoperability

[Back to specializations](../README.md) · [Main roadmap](../../README.md)

## Prerequisites

Networking, messaging, security, and device lifecycle.

## Topics to learn

- [ ] Distinguish application interoperability from radio/network connectivity: Matter, Thread, Wi-Fi, BLE commissioning, and Zigbee occupy different roles.
- [ ] Study device models, capabilities, attributes, commands, discovery, commissioning, and ownership.
- [ ] Understand Thread mesh roles and border routers; inspect what is reachable locally and what depends on cloud services.
- [ ] Study Matter fabrics, commissioning credentials, access control, device attestation concepts, and multi-controller behavior using official implementation documentation.
- [ ] Plan reset, ownership transfer, controller removal, update support, and compatibility across software versions.
- [ ] Evaluate local automation, conflicting controllers, stale state, network partitions, and privacy expectations.

## Project

Commission a supported development device into a test ecosystem, exercise reported state and commands, and test controller/network loss plus reset/recommissioning.

## Completion evidence

Deliver a layer diagram, interoperability test matrix, firmware/controller versions, privacy notes, and lifecycle results. Distinguish development interoperability from certified product claims.
