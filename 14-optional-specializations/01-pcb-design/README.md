# PCB Design

[Back to specializations](../README.md) · [Main roadmap](../../README.md)

## Prerequisites

Electronics, firmware interfaces, power budgets, and production requirements.

## Topics to learn

- [ ] Create schematics with connector pinouts, decoupling, power protection, programming access, and test points.
- [ ] Choose footprints from verified component drawings; check pin numbering, polarity, clearances, tolerances, and assembly orientation.
- [ ] Learn placement, return-current paths, ground planes, power routing, switching-noise control, and thermal paths.
- [ ] Study stackups, impedance and signal integrity where needed; follow radio-module antenna keepouts and manufacturer guidance.
- [ ] Run electrical/design-rule checks, review manufacturability, and prepare BOM, fabrication, and assembly outputs.
- [ ] Plan bring-up from visual inspection and unpowered checks through current-limited power, clocks, programming, and peripherals.

## Project

Design a low-voltage sensor board, complete a schematic/layout review, and prepare a manufacturing package. If fabricated, perform documented bring-up and compare measurements with the design budget.

## Completion evidence

Deliver reviewed design files, rule-check results, BOM, assembly notes, and a bring-up plan. Label the design unvalidated until fabricated hardware has been tested.
