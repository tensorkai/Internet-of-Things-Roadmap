# Edge Machine Learning

## Prerequisites

Sensing, statistics, firmware memory budgets, gateways, and testing; add basic linear algebra and model training.

## Topics to learn

- [ ] Define a measurable prediction task and establish a simple non-ML baseline.
- [ ] Collect representative, labeled data; document consent where relevant and track sensor configuration and data provenance.
- [ ] Split data by device, subject, location, or time as appropriate to prevent leakage across training, validation, and test sets.
- [ ] Evaluate class imbalance, false positives/negatives, confusion matrices, and operating thresholds against application costs.
- [ ] Study feature extraction, model size, quantization, memory arenas, inference latency, and energy per prediction.
- [ ] Compare host and target outputs, test unseen operating conditions, monitor drift, version models and preprocessing together, and provide fallback behavior.

## Project

Train an anomaly or classification model on sensor data, compare it with a threshold baseline, and deploy inference to a constrained target or clearly labeled emulator.

## Completion evidence

Report independent test metrics, data-split rationale, target memory/latency/energy results, failure cases, and an update/fallback plan. Do not equate training accuracy with field performance.
