## Domain applications

Apply these skills to agriculture, buildings, environmental monitoring, asset tracking, logistics, wearables, or smart-city infrastructure. An application domain combines several technical categories; it is not a separate replacement for the core engineering path. Healthcare, transport, and other safety-sensitive applications also need specialized domain and regulatory expertise beyond this curriculum.
