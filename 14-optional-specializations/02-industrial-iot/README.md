# Industrial IoT

[Back to specializations](../README.md) · [Main roadmap](../../README.md)

## Prerequisites

Networking, gateways, security, system testing, and sensing.

## Topics to learn

- [ ] Distinguish operational technology from enterprise IT, including availability, maintenance windows, and consequences of process interruption.
- [ ] Learn RS-485 signaling, termination and biasing, Modbus RTU/TCP addressing and data interpretation, and CAN fundamentals.
- [ ] Study OPC UA information models, discovery, identity, and secure configuration; choose protocol depth based on the target equipment.
- [ ] Handle units, register maps, byte/word ordering, poll rates, timestamps, quality codes, and read-only monitoring boundaries.
- [ ] Design segmented access, controlled remote maintenance, gateway buffering, audit logs, and restoration procedures.
- [ ] Understand the roles of PLCs, supervisory systems, historians, alarms, and dedicated safety systems. A learning gateway does not replace a safety controller.

## Project

Connect a simulator or isolated training device to a gateway, normalize its measurements, and test link failure, invalid register data, and restoration.

## Completion evidence

Deliver the protocol map, topology, access policy, failure tests, and deployment assumptions. Demonstrate that monitoring failures do not issue unintended control commands.
