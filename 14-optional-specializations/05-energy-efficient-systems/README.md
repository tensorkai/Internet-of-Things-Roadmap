# Energy-Efficient Systems

[Back to specializations](../README.md) · [Main roadmap](../../README.md)

## Prerequisites

Complete category 15 and a working connected sensor first.

## Topics to learn

- [ ] Compare battery chemistries and approved power-management designs using operating temperature, pulse demand, aging, and service interval.
- [ ] Optimize the whole system: sensor warm-up, MCU sleep, regulators, leakage, radio associations, acknowledgements, and failed transmissions.
- [ ] Explore event-driven acquisition, batching, compression, adaptive reporting, and the tradeoff between freshness and energy.
- [ ] Evaluate BLE connection intervals, mesh sleepy-device behavior, LoRaWAN receive behavior, or cellular power-saving features for the chosen implementation.
- [ ] Assess energy harvesting using worst-season input, conversion/storage losses, and behavior when energy is insufficient.
- [ ] Measure across real workloads and environmental conditions; distinguish an estimate from a demonstrated service interval.

## Project

Optimize the same sensor application through at least three measured revisions while preserving specified sensing and delivery requirements.

## Completion evidence

Deliver before/after current traces, an energy budget, battery-life assumptions, and evidence that reduced consumption did not break responsiveness or reliability.
