# Mathematical Foundations

[Back to roadmap](../README.md)

## Prerequisites

Basic arithmetic; practice with category 02.

## Topics to learn

- [ ] Rearrange equations; use SI units, prefixes, dimensional analysis, scientific notation, ratios, and percentage error.
- [ ] Convert binary and hexadecimal; understand signed/unsigned integers, two's complement, overflow, truncation, and floating-point precision.
- [ ] Use Boolean algebra, truth tables, masks, shifts, and bit fields to interpret register values.
- [ ] Calculate mean, median, variance, standard deviation, percentiles, and confidence limits at an introductory level. Distinguish random noise, bias, precision, and accuracy.
- [ ] Fit a simple linear calibration; track residual error and propagate uncertainty through basic calculations.
- [ ] Study sample rate, signal bandwidth, aliasing, quantization, moving averages, exponential smoothing, and filter delay. Sampling choices need knowledge of the physical signal.
- [ ] Calculate data rates, packet overhead, buffer capacity, storage growth, duty cycle, average power, and estimated operating life with explicit assumptions.
- [ ] Introduce logarithms and decibels for link budgets. For signal-processing or control specialization, add complex numbers, calculus, frequency-domain analysis, and linear algebra.

## Hands-on work

1. Convert simulated ADC values to physical units, including boundary values and uncertainty.
2. Plot raw and filtered noisy samples and measure the additional response delay.
3. Prepare a spreadsheet or script estimating a day's telemetry volume and outage buffer needs; cross-check one result by hand.

## Completion evidence

- [ ] Include units and assumptions in every calculation and explain the likely sources of error.
- [ ] Show tests for overflow, invalid ranges, calibration endpoints, and sampling assumptions.

Keep code, diagrams, measurements, and notes from these exercises with your project. Record failures and fixes, not just the successful demonstration.
